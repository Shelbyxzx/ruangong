Features

为“公平选题”而设计的核心能力

不只是“能选课”，而是让每一个分配结果都可解释、可追溯、可复现。

🎲

公开种子随机序号

基于 Fisher-Yates 洗牌，公开随机种子。任何人用相同种子即可离线重放出完全相同的序号，杜绝暗箱操作。

可复核性
📋

志愿分档统一匹配

先处理所有人的第一志愿，再处理第二志愿……同一档位内按随机序号升序录取，录满即止。规则对所有学生一致。

公平匹配
⏱️

第二轮按序补选

未匹配学生按随机序号依次限时选择剩余名额。超时或放弃自动跳过并顺延，避免流程卡死。

兜底机制
🛠️

人工调剂 + 全程留痕

教师或管理员可对仍未匹配的学生进行人工调剂。每一次操作都写入只追加的审计日志，不可篡改。

可追溯
⚖️

申诉与仲裁

结果公示后学生可提交申诉，管理员调取审计日志进行裁决，裁决结论公开可见。

争议解决
🔧

规则配置化

志愿数量、补选时限、申诉时长等参数通过后台配置调整，改规则不改代码。

灵活可配
Matching Pipeline

三轮渐进式匹配

每一轮都有明确的进入条件和退出条件，逐层兜底，不留“无解”学生。

1

志愿匹配 · 按档位统一处理

从第一志愿到最后一志愿逐档处理。对每个仍有名额的课题， 取该档位填报此题且未被录取的学生，按随机序号升序录取至名额满。 一轮结束后自动锁定志愿窗口。

志愿顺序 = 优先级 同档按序号升序 自动锁窗 结果立即公示
2

按序补选 · 实时排队

第一轮未匹配的学生按随机序号排队，依次获得限时补选机会。 可以选择剩余名额中的课题，也可以放弃本轮。超时未操作自动跳过并顺延。

随机序号排队 限时选择 超时自动顺延 实时状态可见
3

人工调剂 · 兜底与留痕

对第一、二轮仍未匹配的学生，教师可将学生调剂到自己名下仍有名额的课题， 管理员可操作任意课题。调剂理由和操作人一并写入审计日志。

教师限自己课题 管理员全量权限 调剂理由留痕 审计可查
Roles

三种角色，各司其职

学生填志愿，教师出题与调剂，管理员控制流程与仲裁。

🎓

学生

STUDENT
  • 浏览题库大厅，按教师 / 难度 / 关键词筛选课题
  • 在志愿窗口期内填报和修改志愿，调整优先顺序
  • 查看自己的志愿状态和匹配结果
  • 第二轮补选时按序号限时选择剩余课题
  • 结果公示后提交申诉并查看仲裁结论
📖

教师

TEACHER
  • 发布自建课题（基础课题由管理员维护）
  • 查看选自己课题的学生志愿与匹配状态
  • 关闭自建课题（已有学生填报的不可关闭）
  • 第三轮人工调剂：将未匹配学生调剂到自己名下有余量的课题
  • 查看与自身课题相关的申诉列表
⚙️

管理员

ADMIN
  • 管理题库：创建基础课题、调整容量与开放状态
  • 生成并公示随机序号（可指定公开种子）
  • 控制轮次：锁窗、执行第一轮、开放第二轮、开关申诉期
  • 查看全量匹配结果、审计日志和用户列表
  • 裁决学生申诉，调整系统规则参数

LAN Mode

一台电脑启动，全班同时使用

主机运行后端，同学在同一局域网打开地址申请接入，主机审批后即可使用。

🖥️ 主机端

双击启动脚本后，控制台会打印可分享的局域网地址。

http://192.168.x.x:8000/

在页面顶部「主机联机管理」中查看待审批申请、在线设备， 并可一键复制分享地址。需要放行防火墙时运行配套的防火墙脚本。

📱 同学端

在同一局域网内，按以下步骤接入：

  1. 打开浏览器，输入主机分享的局域网地址
  2. 在联机弹窗中填写称呼并提交申请
  3. 等待主机在「主机联机管理」中批准
  4. 批准后自动获得令牌，直接登录使用

也可以双击「连接主机.bat」，自动扫描局域网并打开正确的主机页面。
